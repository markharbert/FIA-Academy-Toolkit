Step 4: Prevent duplicates permanently

Email normalization

Normalize emails everywhere:

const normalizedEmail = email.trim().toLowerCase()

Apply normalization on:

signup with email/password

OAuth callback user creation

account profile email updates

admin updates

Database constraints

Add a unique index on normalized email.
Options:
A. Store normalizedEmail column and unique index on it (recommended).

Users.normalizedEmail (lower(trim(email)))

Unique index on normalizedEmail
B. If DB supports functional indexes, create a unique index on lower(trim(email)).

Implement in migrations.

Race condition protection

When creating users via OAuth:

Wrap user creation + identity creation in a transaction.

If user create fails due to unique constraint, re-query the existing user and link identity to it.

Identity linking rules

If OAuth provider returns an email:

Attempt to find user by normalizedEmail first.

If found, link identity instead of creating a new user.

If identity already exists by providerUserId:

Always use that user.
