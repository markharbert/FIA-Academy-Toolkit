Role: You are a senior frontend developer working inside my existing Replit project. Update the current app’s visual design system and UI styling to match the brand palette and layout rules below. Do not change core functionality. Do not remove existing pages or flows. Your job is purely UI, spacing, and styling.

Design Goals

Clean, modern UI with lots of white space.

High contrast navigation and footer using dark blue backgrounds and bold white text.

Red buttons as the primary action color.

Light blue used only as subtle accents, not as the main background.

Keep it simple and readable on mobile.

Brand Color Palette

Dark Blue: #06092a

Light Blue: #3f92cc

Red: #da0010

White: #ffffff

Global Layout Rules

Default page background is white.

Use generous padding and spacing:

Page padding: 24px desktop, 16px mobile

Section spacing: 24 to 40px

Card padding: 20 to 24px

Constrain content width so it breathes:

Max content width: 1100px

Center the main container

Typography

Use a clean system font stack.

Keep headings bold and readable.

Body text should be dark blue or near black for contrast on white.

Header and Navigation
Requirements

Header background color: Dark Blue (#06092a)

Navigation text color: White (#ffffff)

Navigation text weight: bold

Logo remains top left.

On mobile:

Use a hamburger menu or stacked nav.

Keep dark blue header background and bold white nav text.

Footer
Requirements

Footer background color: Dark Blue (#06092a)
