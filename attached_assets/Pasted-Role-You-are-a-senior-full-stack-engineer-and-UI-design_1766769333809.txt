Topic Pulse Finder: what it must do

A. Inputs
Provide a simple input box plus optional advanced settings.

Required input

Niche seed: keywords or a short phrase. Example: “keto snacks” or “email marketing for beginners”

Optional inputs

Affiliate product name (if they already know it)

Audience level: beginner, intermediate

Tone preference: friendly, direct, coach style

Video type: review, top list, vs, tutorial, problem fix, beginner guide

Region: US, UK, CA, AU, global

Recency window: 7 days, 30 days, 90 days

B. Topic sources and signals
The tool should produce topics using multiple signals, then combine them into a single ranked list.

Use these sources (minimum set)

YouTube autocomplete suggestions for the seed phrase

YouTube search results metadata for those suggestions (top videos, view counts, publish recency, channel size)

Google Trends (if available via API or a fallback approach) for rising interest signals

Reddit and forum style signals (optional first release, but recommended): pull common questions and repeated phrases from relevant subreddits or sources

If APIs are not available, implement graceful fallbacks

If YouTube Data API is not configured, still show autocomplete-based topics and label them “autocomplete only.”

Allow the admin to plug in API keys later without code changes.

C. Output for each topic
Each topic card must display:

Topic title (human friendly)

Keyword phrase (the exact query)

Intent label: review, comparison, how-to, problem fix, beginner guide

Demand signals:

Autocomplete present (yes/no)

Relative interest trend: rising, steady, falling, unknown

Freshness score based on how many top results were published in the last 90 days

Competition score based on average channel size of top results and how “locked up” the top results seem

A single “Opportunity Score” from 0 to 100 that you compute from the above signals

A short “Why this topic” explanation in plain language

Important: show the reasons, not just the number. Members need confidence.

D. Topic details panel
When a topic is clicked, show a details view with:

Suggested video angles (3 to 5 angles)

Suggested hook ideas (5 hook lines)

Suggested title options (10)

Suggested thumbnail text options (5)

Common questions people ask about this topic (pulled from sources when possible)

A checklist for the user to validate the topic:

Can you solve a specific problem?

Can you show proof or a demo?

Can you naturally mention an affiliate product?

Then provide two buttons:

Generate Script

Save Topic

Script Generator requirements

A. Script creation flow
When the user clicks Generate Script:

Ask for minimal details in a small modal:

Video length target: 3 to 5 minutes, 6 to 10 minutes, 10 to 15 minutes

Affiliate offer name

Affiliate link placeholder label (they can paste link later)

Primary promise of the video in one sentence

Optional: their personal angle or quick story (one paragraph)

Create the script using Mark’s 5-part video creation formula.

B. Output format
The generated script must be structured like this:

Hook

10 to 20 seconds

One strong promise

One curiosity line

One quick “who this is for”

Set the Hook

20 to 40 seconds

Agitate the problem

Show what will happen by the end of the video

Transition line into the main content

First Call to Action

Quick, not salesy

Subscribe or comment prompt that fits the topic

If appropriate, mention “I dropped a resource below” but do not hard sell

Content

Clear numbered sections with timestamps

Examples and simple explanations

Optional mini story or proof

1 to 3 natural mentions of the affiliate offer, framed as “this can help with X”

Include “on-screen text” suggestions for key moments

Include “B-roll ideas” suggestions for key moments

Final Call to Action

Clear next step

Mention the affiliate link placeholder and what it helps them do

Suggest a related next video topic from the Topic Pulse list

C. Script variations
After generating the main script, also generate:

A short version for a YouTube Short (30 to 45 seconds)

A pinned comment draft

A description draft that includes:

2 line summary

the affiliate disclosure line

link placeholder section

5 to 10 tags suggestions

D. Save and export

Save script to the user’s library with topic metadata.

Provide buttons:

Copy full script

Copy Shorts script

Copy pinned comment

Copy description

Backend logic details

Topic generation pipeline

Take seed query.

Generate 20 to 50 candidate queries via:

YouTube autocomplete

Related keyword expansion (simple synonyms, “best”, “review”, “vs”, “how to”, “for beginners”, “2026”)

For each candidate query:

Pull top N YouTube results and collect:

view counts

publish dates

channel subscriber count (if accessible)

video length

title patterns

Compute signals:

Freshness: % of top results in last 90 days

Competition: average channel size and dominance of top videos

Demand: presence in autocomplete, plus trend data if available

Compute Opportunity Score 0 to 100.
Explain it in plain language.

Script generation

Use the selected topic’s data to inform script.

Use the 5-part formula exactly and label each section.

Keep the tone conversational and direct.

Avoid hype and vague claims.

Add practical examples and clear steps.

Performance

Cache results per seed query and region window for at least 24 hours.

Debounce search requests.

Add server-side rate limiting per user.
