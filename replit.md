# Academy Toolkit

## Overview
Academy Toolkit is a web application designed for private practice video marketing. It enables users to upload videos, receive automatic transcriptions, and get AI-powered scoring and improvement suggestions based on a 5-part video formula: Hook, Set the Hook, First CTA, Content, and Final CTA. The application prioritizes private practice with no public sharing features, and videos persist indefinitely unless explicitly deleted. The platform also includes comprehensive email marketing tools, a daily method of operation tracker, and a personalized dashboard to provide a holistic suite for marketing professionals.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture

### Core Technologies
- **Frontend**: React 18, TypeScript, Vite, Wouter, TanStack React Query, shadcn/ui (Radix UI), Tailwind CSS, React Hook Form with Zod.
- **Backend**: Node.js, Express, TypeScript (ESM), RESTful JSON API.
- **Data Storage**: PostgreSQL with Drizzle ORM, Drizzle Kit for migrations.
- **File Storage**: Local filesystem (Multer) with architecture designed for future S3 migration.

### Key Features and Design Decisions
- **AI-Powered Video Analysis**: Utilizes AI for transcription and scoring against a 5-part video formula, with feedback tailored to user-selected goals (sales, lead, education, recruit).
- **Monorepo Structure**: Organized into `client/`, `server/`, and `shared/` directories for type-safe development.
- **User Authentication & Session Management**: Custom session-based authentication with bcrypt password hashing and Express sessions.
- **Video Processing Pipeline**: Audio-first processing for rapid transcription, with parallel generation of HLS streams and video previews. Users can retranscribe up to 3 times.
- **Reporting**: Downloadable branded PDF reports of session scores.
- **User Experience**: Theming (Light/Dark/System), folder organization with drag-and-drop, device selection persistence, and intuitive UI components.
- **Email Tools Hub**: A central hub for email marketing tools, including:
    - **Sender Reputation**: Integrates with Google Postmaster Tools for domain reputation, spam rate, and authentication metrics.
    - **Inbox Analyzer**: Provides detailed analysis of emails (authentication, sender trust, spammy language, technical health, content quality, CAN-SPAM compliance) using a unique seed address per user.
    - **Inbox Placement Monitoring**: Tracks email placement across various seed inboxes (primary, promotions, spam, etc.) using Google OAuth.
- **DMO Tracker**: A Daily Method of Operation tracker for users to log activities, track streaks, earn points, and receive milestone badges.
- **Dashboard**: A live command center displaying real-time statistics and activities from all integrated tools. Hard-capped at 7 cards to prevent clutter. Layout: a dark gradient hero strip with greeting + 4-tile KPI ribbon (DMO points today, videos scored, competitor emails 7d, new alerts), then Row 1 — three vivid daily-signal tiles (DMO Streak amber, Video Practice rose, Inbox Analyzer sky), Row 2 — two wide tiles (Competitor Pulse violet/fuchsia surfaces Inbox Intel `/api/inbox-intel/insights` leaderboard + anomalies + Compare button; Email Health emerald/teal surfaces Postmaster reputation + last inbox-placement test result), Row 3 — Recent Activity (extended to include Inbox Intel anomaly events) and Quick Actions (slimmed; saved-topics + scripts now appear as count badges instead of their own card). All tiles share a `GradientTile` shell with a top accent gradient bar and corner glow; numbers use gradient `bg-clip-text` for vivid emphasis. KPI ribbon numbers are solid white for AA contrast on the gradient backdrop. No charts on the dashboard — chart-style trends live on each tool's detail page.
- **Teleprompter (standalone)**: Members-only tool at `/teleprompter` for scrolling any pre-written script. Two-column layout — left column lists saved scripts (newest first, hover-reveal delete, click-to-load); right column has title input, large textarea (max 100k chars), live word/read-time count, and a "Tips" panel. Three actions: **Open Teleprompter** (auto-saves before launching the popup), **Save to library** / **Save changes**, **Upload .txt** (max 500KB, fills textarea + auto-fills title from filename). Scripts persist server-side in the new `teleprompter_scripts` table (id, user_id, title, content, created_at, updated_at) with cascade-on-user-delete. CRUD endpoints at `/api/teleprompter/scripts*` are auth-required and ownership-scoped via `requireAuth` + `userId` filter on every query. The teleprompter popup window itself is a single shared helper at `client/src/lib/teleprompter.ts` (`openTeleprompter({title, sections})`) — same dark scroller, Slow/Med/Fast speed buttons, 5-second countdown, Play/Pause, Restart, A−/A+ font-size buttons (5 presets: Small 24px / Medium 32px / Large 44px / X-Large 56px / XX-Large 72px, default Medium, choice persisted in `localStorage` under `teleprompter:fontSizeIdx`), and Space/S/M/F/R/+/− keyboard shortcuts as the Scripts tool. Standalone passes one unlabeled section; the existing Video Trends scripts page passes labeled 5-part sections (HOOK/SET THE HOOK/FIRST CTA/CONTENT/FINAL CTA) with their accent colors. Hub tile added to `/video-tools` (slate→zinc gradient, MonitorPlay icon).
- **ClickFunnels Integration**: Grants/revokes app access based on ClickFunnels enrollment events, provides SSO capabilities, and enforces membership checks during authentication.
- **Account Page**: Members-only layout (max-w-2xl) with three gradient-accented cards — Profile (Gravatar + display/first/last name editable, email read-only and tied to CF membership), Membership (Active/Inactive badge driven by `cfEnrolled && !cfRevokedAt`, member-since date from `cfEnrolledAt`, "Manage on ClickFunnels" external link), and Recent Activity (last 10 entries from `user_action_log` via new `GET /api/account/activity`, each row showing a tone-colored lucide icon, friendly action label, short device string + IP, and relative timestamp). Old Connected Sign-In Methods / set-password / Google connect UI removed; underlying endpoints retained but unused from the UI.
- **Help Documentation**: In-app documentation hub with illustrated guides for all features.
- **Inbox Intel**: Competitor email intelligence tool. Members create up to 20 competitor trackers, each with up to 5 unique private seed addresses on `watch.fearlessmarketinglab.com`. Use the seed addresses to subscribe to competitors' email lists; incoming emails are automatically captured, parsed (sender, subject, links, images, ESP fingerprint, authentication), and stored. Latest 100 full-HTML captures kept per tracker (oldest auto-pruned), all metrics retained forever, up to 25 pinned emails per tracker preserved indefinitely. Pure rule-based analysis — no AI generation. Requires SendGrid Inbound Parse subdomain `watch.fearlessmarketinglab.com` configured to POST to `/api/inbox-intel/inbound`.
    - **Organic seed addresses**: seed local-parts are generated to look like real personal mailboxes (e.g. `sarah.thompson83`, `mike.r.davis`, `jenniferlee47`, `kate_brooks`, `dmiller2024`) — combinations of common first/last names with mixed separators and optional numeric suffixes. This avoids ESP rejection of robotic-looking signups. The full local-part is the lookup token; uniqueness is enforced via DB collision-retry. Legacy `track-{nanoid}` addresses still resolve via a permissive inbound parser.
    - **Per-competitor analytics tab** (Phase 2): cadence heatmap (7 days × 24 hours), 90-day send-volume chart, subject line stats (avg length, % emoji, % all-caps, top opening words, longest/shortest), ESP fingerprint with confidence and change count, authentication audit (SPF/DKIM/DMARC pass rates, list-unsubscribe coverage, weak-auth count), and content patterns (avg words/links/images, % UTM-tagged, top destination domains). All computed forever from retained metric columns even after full-HTML bodies are pruned.
    - **ESP detection** combines high-confidence header signals with ~25 HTML body fingerprints (tracking-link domains, open-pixel hosts, footer patterns) covering Mailchimp, Klaviyo, HubSpot, ActiveCampaign, ConvertKit, Constant Contact, Campaign Monitor, ClickFunnels, Keap, MailerLite, Drip, AWeber, GetResponse, beehiiv, Substack, Flodesk, Omnisend, Brevo, SendGrid, Postmark, Mailgun, Salesforce Marketing Cloud, Pardot, and Oracle Eloqua.
    - **Unified feed** (`/email-tools/inbox-intel/feed`): cross-competitor chronological stream with day-grouped sections, search (subject/sender), date preset (today / 7d / 30d / 90d / all), competitor multi-select, ESP filter, and pinned-only toggle.
    - **Website screenshots** on competitor tiles: when a tracker has a website, the server captures a 1280×720 JPEG via Microlink (`api.microlink.io`, no key required) and stores it in object storage at `/objects/inbox-intel/screenshots/{trackerId}-{ts}.jpeg`. Capture runs asynchronously after tracker create and on website change; tile shows "Capturing preview…" until ready and polls every 6s. Tracker detail page has a "Refresh preview" button. SSRF-safe URL normalization rejects localhost / private IPs.
    - **Funnel detection tab** (Phase 3): pure rule-based on-demand analysis (no schema changes, no AI). Two-stage classifier in `server/inboxIntelFunnel.ts`: Stage 1 cross-seed alignment groups emails by normalized subject across seeds — if their offsets-from-signup spread is ≤15 min the group is automated (high confidence), if their wall-clock receivedAt spread is ≤15 min it's broadcast (high confidence). Stage 2 single-seed heuristics: first email with offset ≤30 min is automated (medium), tight-cadence runs are automated (low), gap > 3× early-median or > 7d ends the welcome era (subsequent emails → broadcast). Welcome series is built from the longest leading auto-run on the best seed, deduped by normalized subject with median offset across matching seeds. Funnel tab shows verdict card with confidence badge, step-by-step welcome sequence (clickable to open email), and per-seed timeline visualization with dots positioned by time-since-signup (amber=auto, violet=broadcast, gray=unclassified). Endpoint `GET /api/inbox-intel/trackers/:id/funnel` returns `FunnelAnalysis`.
    - **Cross-competitor insights and compare** (Phase 4): Hub page shows a "What's changed this week" insights panel powered by `server/inboxIntelInsights.ts` (`computeInsights()`) — a pure function that scans all of the user's trackers and produces (a) a top-5 leaderboard of trackers by emails-in-last-7-days with week-over-week % change and (b) anomaly events of four types: `spike` (last 7d ≥ ceil(2×priorAvg+0.5) emails AND priorAvg≥1, severity warn), `gap` (>7d silence after a ≥5-email run with prior avg gap <4d, severity info), `esp_change` (dominant ESP in last 5 differs from prior 20 with ≥3/5 on the new platform, severity alert), `auth_regression` (last-10 SPF/DKIM/DMARC fail rate ≥30% vs prior-20 ≤10%, severity alert). Endpoint `GET /api/inbox-intel/insights` returns `InsightsResponse`. A new `/email-tools/inbox-intel/compare` page lets users pick up to 4 trackers and view side-by-side cards (screenshot, activity, ESP confidence, busiest day/hour, subject style, auth pass rates, welcome funnel summary) backed by `GET /api/inbox-intel/compare?ids=a,b,c` (max 4 enforced server-side, unauthorized IDs silently dropped, client order preserved). Compare card uses `summarizeForCompare()` which reuses existing analytics + funnel computations.
    - **CSV export** (Phase 4, pulled forward from Phase 5 by user request): `GET /api/inbox-intel/trackers/:id/emails.csv` (single tracker) and `GET /api/inbox-intel/feed.csv?...` (cross-tracker, accepts the same filters as `/feed`). Both authentication-required and ownership-scoped via the same shared filter logic. CSV generation in `server/inboxIntelCsv.ts` uses RFC-4180 escaping plus CSV-injection guard (prefix any cell starting with `=`, `+`, `-`, `@`, tab, or CR with a single quote). Exports cap at 5000 rows. Download buttons appear in the tracker detail header, the unified feed filter bar, and on each compare card.

## External Dependencies

### AI Services
- **Google Gemini API**: For video transcription.
- **OpenAI API**: For transcript scoring and feedback generation.

### Database
- **PostgreSQL**: Primary database for all application data.

### Email Services
- **SMTP**: For sending password reset emails and system notifications.
- **SendGrid**: For receiving inbound parsed emails for the Inbox Analyzer.

### OAuth Providers
- **Google OAuth**: For user authentication, Google Postmaster Tools integration, and Inbox Placement Monitoring (Gmail access).

### Third-Party APIs
- **ClickFunnels API**: For membership enforcement and SSO.
