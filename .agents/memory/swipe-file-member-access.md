The Swipe File under Library must be available to all Academy members, not just administrators.

**Why:** The user explicitly requested member availability.

**How to apply:** Keep the navigation and page available under the existing member sign-in and access rules. This changes who can use the feature, not which members own individual saved items; it is not a request to publish everyone's collections.
