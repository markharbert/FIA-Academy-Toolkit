description: Chrome Web Store data-category interpretation, including local processing, IP addresses, and saved source URLs.
---

Chrome Web Store disclosures cover handled data, including local processing, not only data uploaded to a server.

**Why:** Google's user-data FAQ explicitly includes local processing and storage. The Store's Location category includes IP addresses, and its web-browsing definition includes URLs and domains the user interacts with.

**How to apply:** Do not interpret Location as GPS only or Web history as full browser-history collection only. Disclose IP handling when security controls or logs process it, and explain that captured source URLs/titles concern member-selected pages rather than continuous browsing surveillance. Recheck the actual behavior before completing future submissions.

The three data-use certifications require truthful business practices; source-code inspection alone cannot establish whether data is sold or used elsewhere.

**Why:** The publisher certifies permitted transfers, single-purpose use, and no creditworthiness/lending use.

**How to apply:** Explain that all three are required, but never instruct the publisher to certify them regardless of the truth.
