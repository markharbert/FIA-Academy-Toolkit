---
name: Palette result visibility
description: Product decision for how the Chrome extension presents extracted website palettes.
---

The extracted palette result should be a centered, prominent modal with a dimmed backdrop, rather than a small bottom-of-screen panel.

**Why:** The palette worked functionally but was easy to miss, especially when the user needed to save it.

**How to apply:** Keep the modal large enough to clearly show all six swatches and the Save to Swipe File action while remaining responsive on small screens.
